# AOBA / X Operator

架空AIキャラクター「あおば」のX運用を、物語・進捗・投稿下書きと一緒に設計するiPhone向けWebアプリです。

## GitHub Pagesで使う

1. この `aoba-x-operator` フォルダをGitHubの新しいリポジトリに置く
2. `main` ブランチへプッシュする
3. GitHubの **Settings → Pages → Build and deployment** で **GitHub Actions** を選ぶ
4. Actions完了後に表示されるURLをiPhoneのSafariで開き、「ホーム画面に追加」を選ぶ

Xへの投稿は、保存済みの下書きをXの投稿画面へ渡すだけです。ログイン情報や投稿権限はアプリに保存しません。

下書き・タスク状態は、各ブラウザ内にだけ保存されます。
