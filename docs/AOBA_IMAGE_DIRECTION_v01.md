# AOBA｜画像生成・撮影表現ルール v01

- 更新日: 2026-08-16
- 状態: ユーザー確認済み現行方針。非セルフィーの撮影関係と仕事着の最終例を確定（2026-08-16）
- 対象: AOBAのX投稿用画像

## 1. 人物と撮影関係

- AOBAは23歳の成人の架空人物とする。4年制大学を卒業して不動産会社へ新卒入社し、現在は入社1年目・社会人1年目。顔・年齢感・体格・職業・生活空間の連続性を保つ。
- 画像生成や人物紹介では基本年齢を「23歳」と表記する。「新卒入社1年目」は経歴の補足として併記できる。25歳・33歳など過去の年齢設定は使用しない。
- セルフィー以外は、親しい人が近い距離から撮った写真として構成し、AOBA本人も撮られていることを意識している状態を必須とする。
- 非セルフィーでは、AOBAの視線、身体の向き、表情、手元の動作を撮影者またはカメラへ返す。第三者との会話や接客の一部を、撮影者が偶然切り取ったような構図を通常型にしない。
- 撮影者との一対一の関係が伝わるよう、レンズを見る、撮影者の声へ微笑む、持っている物をカメラへ見せる、振り返って応じるなど、撮影への反応を一つ入れる。
- 自宅シーンは、手持ちインカメまたは固定鏡によるセルフィーを原則とする。セルフタイマーや第三者撮影は、企画上必要でユーザーが個別に認めた場合だけ例外とする。
- 基本の目線はカメラへ向ける。例外として、作業や移動に必要なときだけ手元や進行方向へ外す。
- 仕事写真でも、作業中の横顔や第三者への説明を主役にせず、撮影者へ身体と目線を向けた反応を優先する。新人らしい少しの緊張や照れを残しつつ、目元と口角が自然にほどけた親しみのある笑顔とする。
- 無表情の硬さを避け、目元と口角が自然にほどけた微笑み、会話の途中の笑い、少し照れた反応を優先する。
- 大笑い、過剰な驚き、モデル風の決め顔、誇張した身振りは禁止する。明るさは保ちつつ、演技に見えない範囲に収める。

## 1.1 自宅・暮らし・ファン化の固定条件

- 自宅はAOBA HOME C01の固定レイアウトを基準とする。間仕切り壁横の固定鏡、窓中央、エアコン右上、物干しラック右、ソファ左、ローテーブル中央、ベッド右の関係を保つ。
- ベッド、ソファ、ローテーブル、窓、収納、物干しラック、鏡などの固定家具は動かさない。変えるのは飲み物、クッション、本、衣類などの可動物だけとする。
- 基本は一人暮らしとして描く。人物はAOBA一人だけとし、二人分のマグ、食器、上着、靴、寝具、歯ブラシなど、同居人や恋人を示す小物を置かない。
- 自宅写真は単なる生活記録ではなく、ファン獲得を目的とする。近い距離、やわらかい表情、目線、生活の小さな動作によって「また見たい」「話しかけたい」と感じる親近感を作る。
- 自宅セルフィーでは、腕の伸び、画角、インカメ特有の近距離感を自然にし、撮影機構が成立しない第三者視点を混ぜない。
- 自宅では、外出着や仕事着ではなく、見た瞬間に部屋着と分かる服装を必須とする。ブランド傾向を使う場合も、柔らかい素材、ゆとりのある形、くつろげる重ね着へ翻訳する。

## 1.2 セルフィーの変化ルール

- セルフィーの撮り方とポーズは毎回変える。同じ「ソファ正面・片腕を前へ伸ばす・上半身・小さな笑顔」の組み合わせを連続生成しない。
- 新しいセルフィーは、直前のセルフィーから次の6軸のうち最低3軸を変更する。
  1. カメラ位置: 目線高、少し上、斜め横、真上、固定鏡
  2. 写る範囲: 顔寄り、肩まで、上半身、膝まで、全身
  3. 姿勢: 立つ、ソファに深く座る、床座り、膝を立てる、横になる、ベッドに腰掛ける
  4. 撮影する腕: 右手、左手、両手持ち、鏡越し
  5. 空いた手の動作: 髪、袖、頬、マグ、本、クッション、イヤホン、布団
  6. 表情・生活動作: 微笑み、吹き出す直前、眠気、照れ、考え中、飲む直前、読みかけ、髪を整える途中
- 過去8枚以内では、カメラ位置・姿勢・手の動作の完全一致を禁止する。似た衣装でも撮影機構と身体の向きを変える。
- ウインク、ピース、指ハート、頬を膨らませるなどの記号的ポーズは全体の2割以下とし、連続使用しない。主力は生活動作の途中とする。
- カメラ目線を基本にするが、シャッター直前の一瞬だけ飲み物、本、窓へ目線を外す型も混ぜる。目線を外す場合も両眼の注視点を揃える。
- 低い位置から胸や脚を強調する構図は使わない。俯瞰は寝転びセルフィーや膝抱えなど、撮影機構が自然な場合に限定する。
- 腕を伸ばす手持ちセルフィーでは、肩・上腕・肘・前腕・手首の長さと接続を実人体の比率で確認する。遠近感を理由に腕を不自然に長くしない。
- カメラへ伸ばした腕を画面の主役にしない。肘をわずかに曲げ、顔から無理のない距離で持つ。腕が対側の腕より明らかに長い、肩から手首までが胴体に対して過長、前腕だけが引き伸ばされた画像は不採用とする。

### 自宅セルフィーのローテーション候補

1. ソファで目線高の顔寄り。空いた手で髪を耳へかける途中。
2. ソファで少し上から膝抱え。顎は膝へ乗せず、笑い始めの目元を見せる。
3. ベッドに横になり、真上から撮る。布団の端を空いた手で軽く持つ。
4. ベッド端へ腰掛け、斜め横上から肩越しに撮る。振り向く途中。
5. 床に座りソファへ背を預け、ローテーブル上の一人分の飲み物を入れる。
6. 窓際の自然光で上半身。カーテンへ触れた直後にレンズへ戻る。
7. 固定鏡の全身セルフィー。服の裾やカーディガンを整える途中。
8. 固定鏡の上半身セルフィー。スマートフォンで顔を隠しすぎない。
9. 読書中の肩までのセルフィー。本を閉じかけた瞬間。
10. イヤホンを片耳へ入れる途中の顔寄り。音楽に反応した柔らかい笑顔。
11. 入浴後のヘアケア中。タオルや前髪を直している途中で、濡れた衣服表現は使わない。
12. 就寝前のベッドセルフィー。袖や布団で口元を少し隠し、眠気を表情にする。

### 投稿用の選択原則

- 1枚投稿では、顔と表情が主役になる3:4または4:5の縦構図を基本にする。
- 複数枚投稿では、顔寄り、生活動作、姿勢の分かる広めの画角を混ぜ、同じ距離の写真だけを並べない。
- 強いフィルター、美肌の均一化、過剰な背景ぼかしは避け、肌理、服のしわ、生活小物などの社会的手掛かりを残す。
- 直接目線は、硬い決め顔ではなく自然な微笑みや反応と組み合わせる。

## 2. 目線の品質検査

- 両眼の瞳孔と虹彩が同じ注視点へ向いていることを必須とする。
- カメラ目線では、左右の目がレンズ位置へ自然に収束し、寄り目・外斜視・左右別方向にならないよう確認する。
- キャッチライトの位置と大きさを左右で整合させる。
- 生成後は顔の拡大確認を行い、片目だけ横を向く、瞳の形が違う、白目量が不自然な画像は不採用とする。

## 3. 一瞬を切り取る表現

- 動作の完成形ではなく、紙を揃える、カップを置く、髪を耳へかける、振り向く、歩くなどの途中を撮る。
- 非セルフィーの動作途中は、撮影者へ振り向く、鍵や資料を見せる、声をかけられて笑うなど、AOBAと撮影者の関係の中で成立させる。顧客や同僚とのやり取りを主題にしない。
- カメラブレや被写体ブレは時々使用する。ただし顔と両眼は判別できる状態を保つ。
- ブレは紙の端、手先、後れ毛、背景の端などへ弱く限定する。顔全体の流れ、強い残像、全体のピンぼけは禁止する。
- 「失敗写真」ではなく「シャッターが少し早かった自然な写真」に見える強さに抑える。

## 4. 机・家具・小物・資料

- テーブル上の小物と資料は、天板の範囲内へ物理的に収める。
- 紙、カップ、スマートフォン、ペン、PC、マイソクなどが天板から不自然にはみ出す、浮く、食い込む、重複する状態は禁止する。
- 画面端で小物や資料を中途半端に切らない。意図して切る場合も、物の形と置かれ方が理解できる余白を残す。
- 不動産業務の資料は、建築図面だけでなくマイソク、物件概要、写真付き募集資料を優先する。
- マイソクは外観写真、室内写真、間取り欄、情報ブロックが見える構成とするが、住所、価格、会社名、連絡先などは読めない状態にする。

## 5. 自然な素肌の方向性

- 目的は性的な強調ではなく、生活感、季節感、素材感、親近感を出すこと。
- 素肌は一か所へ集中させず、腕、肩、首元、鎖骨、膝下などへ分散する。
- 顔、表情、職業動作、生活動作を常に主役とし、胸、尻、股、太ももなど特定部位を主役にしない。
- 生地はコットン、リネン、細番手ニット、落ち感のあるレーヨン混など、日常的で不透明な素材を基本とする。
- シースルー、シアー、ざっくりした網目は使用できる。ただし不透明なインナーや裏地と重ね、透けは袖、肩、裾など素材感が伝わる範囲に限定する。
- 濡れ、極端な密着、深い胸元、短すぎる丈、下着風、身体部位だけの切り取りは禁止する。
- カメラは原則として目線から胸の高さ。胸元や脚を強調するローアングル、俯瞰による胸元強調、身体をなぞるような構図は禁止する。

## 6. 場面別の衣装候補

### 衣装共通

- 服の種類、襟、袖、丈、重ね方、素材を固定化せず、投稿間で豊富に変える。
- 季節感を必須にする。春は軽いシアー素材と淡色、夏は通気性のよいノースリーブや薄手生地、秋はベスチェの重ね着や長袖、冬はざっくり網目のカーディガンや細番手ニットを中心にする。
- シースルーブラウス、シアーなワンピース、ファッション用ベスチェ、ざっくり網目のカーディガンを候補に含める。必ず日常着として成立する不透明なインナーまたは裏地を合わせる。
- AOBAの休日私服の中心はAmeri VINTAGE。変形ブラウス、レイヤードワンピース、アシンメトリー、異素材切り替えなど、清楚な色調に一か所だけ癖のある形を好む。
- 仕事にも使える服はUNITED TOKYO、柔らかい普段着はKBFまたはMURUA、特別な一着・憧れはMame Kurogouchi、小物の個性はTOGA PULLAの傾向を参考にする。
- 色はアイボリー、くすんだブルー、セージグリーン、ブラウン、深いボルドー、黒を中心にする。
- ブランド名は人物設定上の好みとして使用し、画像では色、シルエット、重ね方、素材感だけを参考にする。ロゴ、読めるブランド名、商品固有の柄や意匠を複製しない。

### 仕事中

- 仕事着の基本は、不動産会社の接客・内見・物件確認に自然なカジュアルフォーマルとする。上下がそろった濃紺スーツは通常の基本服にしない。
- AOBAは23歳・新卒入社1年目とする。服装と表情は、新人社員らしい若さと初々しさを残し、完成されたキャリアウーマン、営業成績上位、管理職のような強さや貫禄は出さない。
- 仕事着でもAmeri VINTAGEを中心にし、KBFまたはMURUAの若いカジュアルモード感を加える。UNITED TOKYOの構築感は補助にとどめ、堅いジャケットスタイルへ戻さない。
- アシンメトリーネック、片側の小さなドレープ、変形した襟など、一か所だけ若く女性らしいデザインを入れる。実在商品の複製はしない。
- 細番手ニット、ノースリーブニット、柔らかなブラウス、オープンカラートップスを使う。首元、鎖骨、上腕、前腕が仕事場で不自然にならない範囲で見える服を優先し、露出をジャケットやカーディガンで常に隠さない。
- ボトムは明るいグレージュまたはアイボリーのAライン・ミディスカート、柔らかなマーメイドスカートを中心にし、必要に応じてセンタープレスパンツやテーパードパンツも使う。タイトすぎるスカートや短い丈は避ける。
- 色はネイビー、チャコール、グレージュ、アイボリー、くすんだブルーを中心にし、上下を完全に同色で固めない。
- 靴は内見で歩きやすいローファー、フラットシューズ、低めのパンプスを使う。高いヒールを通常装備にしない。
- 社員証は社内や接客時だけ自然に使い、すべての仕事画像へ機械的に付けない。黒または濃いグレージュの実用的なトートバッグを合わせる。
- 不動産らしさは、マイソク、物件写真付き資料、タブレット、鍵、メジャー、募集図面などで示す。建築設計図を主役にしない。
- 肌は上腕、前腕、首元を中心に自然に見せ、資料をそろえる、鍵を確認する、タブレットを操作するなど仕事中の手の動きを同時に写す。
- 上下スーツは、契約、重要な対外対応、会社指定日など、場面上の理由が明確なときだけ例外として使う。
- 2026-08-16承認済みの仕事写真基準は「ダスティブルーのアシンメトリー・ノースリーブニット、アイボリーのハイウエストAライン・ミディスカート、低いストラップパンプス、小さなショルダーバッグ、物件ファイルと鍵」とする。完全固定の制服ではなく、若い新人らしさ、女性らしさ、自然な素肌、ブランド傾向を判断する視覚基準として使う。
- 承認済みの撮影動作は、店舗内で撮影者へ正面を向き、レンズを見て、物件ファイルを身体の前に抱え、鍵を少し持ち上げ、少し照れた柔らかな笑顔を返す形とする。他の人物との会話は入れない。
